# DentaVisit 検討資料

ユーザー提供HTMLを基にした一般公開の静的検討ページです。

- `dashboard/`: 市場調査・事業戦略ダッシュボード
- `prototype/`: DentaVisit UIサンプル（実予約不可）

## 重要な制限

市場数値・統計母数・診療/介護報酬の詳細は一次資料との照合を完了していません。原稿値は未検証として表示しています。法規チェックは法的助言でも適法性診断でもなく、専門家へ相談する論点の整理です。定額SaaS/BPOという名称では適法性は保証されません。

事業所割合39.3%を患者単位の受診転換率として使うことはできないため、新規受診件数の自動計算は停止しました。加算試算は50単位・1単位10円等の簡略化した仮定で、算定や増収を保証しません。

このサイトは実患者情報を扱いません。入力・予約はデモであり、診療機関へ送信されません。公開HTML内に秘密鍵、実患者データ、認証情報は含めないでください。

## 実装

提供原稿の6タブ、2グラフ、加算試算、法規チェック、競合分類、事業案を保持。CDN参照、タブ切替、入力上限、年額表示を修正。危険な断定と未確認競合評を仮説/要確認表示に変更。長文は手動転記のため原稿とのバイト一致ではありません。

GitHub Pages: main ブランチのルートを配信。外部CDNとしてTailwind CSSとChart.jsを使用します。
